# Functional freeze: 0.1.0-beta.1

The `release/0.1.0-beta.1` branch is functionally frozen. Changes on this branch must be limited to:

- reproducible release blockers;
- security or privacy fixes;
- packaging or signing fixes;
- version or release metadata;
- release documentation;
- public-repository preparation that does not alter application behavior.

The following changes are not allowed on the release branch:

- new features;
- UX redesign;
- speculative polish;
- architecture refactors;
- Compose migration;
- dependency upgrades without release justification;
- translation expansion unrelated to a release blocker.

Post-beta work, including incomplete Spanish translation, a visible Sleep Timer countdown, Android Auto polish, Compose migration, legacy architecture work, and new features, remains outside this freeze.
