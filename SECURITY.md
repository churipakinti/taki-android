# Security policy

## Reporting a vulnerability

Please do not open a public Issue when a suspected security or privacy vulnerability would reveal credentials, private server details, personal library data, or usable exploitation steps.

This repository does not currently advertise a private security contact. Before the repository becomes public, the maintainer should enable GitHub Private Vulnerability Reporting. Once enabled, use the repository's **Security** tab to report sensitive vulnerabilities privately.

For non-sensitive security hardening or questions that contain no private details, a normal Issue is appropriate.
